# Radar reference images: sources and licences

All files were downloaded from Wikimedia Commons on 2026-10-24, using the Commons API and `upload.wikimedia.org`. Licence information comes from each file's Commons description page (`LicenseShortName`). Except where noted, every file is a **US federal government work in the public domain**, made by NWS, NSSL or NOAA from NEXRAD WSR-88D data.

The Commons page for each file is `https://commons.wikimedia.org/wiki/<Commons title>`, with spaces replaced by underscores.

Some files were downscaled to Commons thumbnails to keep them near or under 2 MB. These are marked "thumb Npx".

Files I chose not to keep:
- **2013 El Reno RaXPol image.** It comes from a University of Oklahoma radar, and its public-domain tag is doubtful.
- **1999 DOW velocity figure.** It is reproduced from a BAMS (AMS journal) figure, so its public-domain tag is also doubtful.
