# Real storm reference images

Reference photos of real supercell and thunderstorm structure, for storm visuals. All come from Wikimedia Commons (many are NOAA/NSSL/NWS public-domain photos mirrored there). Each was downloaded with curl from the upload.wikimedia.org URL given (a 1280 px wide thumbnail, or the original when it is smaller).
