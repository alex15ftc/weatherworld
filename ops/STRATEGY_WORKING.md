# WeatherWorld Strategy Working

Working strategy exploration for `WeatherWorld`: unresolved questions, pressure tests, and unpromoted thinking too large for `STATUS.md`.

This file is not canonical when it conflicts with `STATUS.md` or `STRATEGY_MASTER.md`.

## How Entries Live and Leave

- Every entry is a heading of the form `### YYYY-MM-DD — Title (open)`. Status is `open`, `promoted`, or `dropped`.
- **Promoted:** move the accepted conclusion into `STRATEGY_MASTER.md` (and `STATUS.md` if it changes operations), add a `HISTORY.md` line if it is a pivot, then delete the entry here.
- **Dropped:** if the reason is worth remembering, add one line under Parked Or Deprecated Frames in `STRATEGY_MASTER.md`; then delete the entry here.
- Long supporting analysis belongs in a memo (`memos/`), linked from the entry, not inline.
- Keep this file under 20 KB. If it is over, the oldest `open` entries are probably stale: resolve them or ask the owner.
- Git history keeps every deleted entry.
