# Memos

Finished internal analysis and decision memos that someone may reread: strategy reframes, market or pain-point findings, pilot agreement reviews, brand architecture, post-mortems.

- One file per memo, flat, named `YYYY-MM-DD_TITLE.md`.
- A memo is finished when written. If it is still changing, it belongs in a work folder or `STRATEGY_WORKING.md`.
- Memos never expire and never move. If a later memo supersedes one, say so at the top of the old memo with a link.
- Memos are evidence of what was thought at the time, not current authority. Accepted conclusions belong in `STRATEGY_MASTER.md` or `STATUS.md`.
- Sourced external research that is not tied to a decision can go in `research/` if this project keeps one.
