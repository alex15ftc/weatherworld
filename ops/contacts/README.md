# Contacts

Use this directory for relationship state, meeting history, and useful org/person context.

Recommended layout:

```text
contacts/
|-- README.md
|-- people/
|   `-- person-slug/
|       |-- PROFILE.md
|       `-- meetings/
|           `-- YYYY-MM-DD.md
|-- orgs/
|   `-- org-slug/
|       `-- PROFILE.md
`-- views/
    |-- active.md
    |-- advisors.md
    `-- intro-sources.md
```

Update contacts only when relationship state, meeting history, next actions, or strategically useful org/person context meaningfully change. Before adding a person or org, search existing records to avoid duplicates.
